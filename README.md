# Globe Quest

Application éducative bilingue FR/DE pour apprendre les **195 pays**, leurs **capitales** et leur **localisation géographique**.

## Fonctionnalités

- Carte mondiale interactive
- 195 pays
- Français / Deutsch / FR+DE
- Cartes de mémorisation
- Quiz pays → capitale
- Quiz capitale → pays
- Quiz pays → continent
- Filtres par continent
- Progression locale
- PWA installable sur iPhone
- Fonctionnement hors ligne après la première visite

## GitHub Pages

1. Crée un dépôt public nommé `globe-quest`.
2. Ajoute tous les fichiers de ce dossier à la racine du dépôt.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**.
4. Branche : `main`, dossier : `/ (root)`.
5. Le site sera disponible à :
   `https://guy2b.github.io/globe-quest/`

## iPhone

Dans Safari :
1. Ouvrir le site.
2. Toucher **Partager**.
3. Choisir **Sur l’écran d’accueil**.

L’application s’ouvrira ensuite comme une mini-app.
